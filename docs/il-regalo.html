The one rule everything hangs on

The model proposes.
The code decides.

No model — NER, LLM, or agent — ever emits a CPE string directly. Models only extract entities (vendor / product / version). The CPE is built, validated against the official ABNF grammar, and matched against the NVD dictionary by deterministic code. A CPE that doesn't parse doesn't exist. Hallucination is structurally impossible, not just unlikely.

The pipeline

→
04

Against the official NVD dictionary, cached & throttled.
→
05
Classify
M1–M3 rules: exact match, new version, new candidate… → CVE lookup.

Escalation, not brute force: titles the fast pass can't resolve are handed to an agent that reasons with four deterministic tools (search the dictionary, validate, classify, submit) — and everything it submits is re-validated by code anyway.

Where every title lands

M1 · M1A · M1B · M1C

High confidence. Exact dictionary match, accepted match, new version of a known product, or a solid brand-new CPE candidate. Ready for CVE applicability.

M2 · M2B

Candidates. Known vendor with a similar product, or a known product under a new vendor. Worth a human (or agent) look.

M3

Everything else. Drivers, KBs, inventory noise, and the genuinely hard tail — the 95% the v2 exists to shrink.
