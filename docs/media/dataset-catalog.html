5 · Convenció d'alta

Tot dataset nou s'apunta al catàleg amb: nom i ruta, origen, rol, files, a git?, publicable?, font exacta (ordre que el genera o procedència), sha256/MANIFEST si és regenerable, i data. Si és gold: mostreig (seed inclosa) i qui l'ha anotat. Si deriva d'un inventari real: confirmació explícita que queda fora de git. Un dataset neix aquí o no existeix — el paral·lel exacte del catàleg de models.
